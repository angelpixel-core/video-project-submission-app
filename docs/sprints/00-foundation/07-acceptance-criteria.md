# Acceptance Criteria

## Evaluation Focus

- [ ] Correct modeling of relationships.
- [ ] Clarity and structure of Rails code.
- [ ] Handling of asynchronous jobs.
- [ ] Clean and functional UI.
- [ ] Efficient and scalable database queries.
- [ ] Thoughtful code organization.

## Bonus

- [ ] Use of partials, helpers, or services.
- [ ] Basic test coverage for models or services.
