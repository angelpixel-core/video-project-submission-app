# Context

## Scenario

We are building a simplified version of the order process of a video editing platform. Clients are logged in, select the video types they want created from their footage, simulate a payment, and get assigned a Project Manager (PM) who oversees the project.

A video type is a specific kind of edited deliverable such as a highlight reel, full documentary edit, teaser, or social media clip. Each one has its own pricing and format.

## Key Points

- [ ] Clients are already logged in.
- [ ] Clients select video types from their footage.
- [ ] Checkout is simulated.
- [ ] A Project Manager oversees each project.
- [ ] Video types have pricing and output format.
