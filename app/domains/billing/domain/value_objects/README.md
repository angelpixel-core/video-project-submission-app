# Billing Value Objects

Immutable billing concepts belong here.

This remains the physical `billing/` namespace; `invoicing` is the target product vocabulary.

Current value objects:

- `billing_identity.rb`
- `invoice_id.rb`
- `invoice_number.rb`
- `invoice_status.rb`
- `tax_amount.rb`

## Rule

- Value objects carry meaning, validation, and comparison semantics.
